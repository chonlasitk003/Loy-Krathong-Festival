# Loy Krathong 3D Festival & Contest (เว็บแอปพลิเคชันประกวดและโหวตกระทงออนไลน์ 3D)

เว็บแอปพลิเคชันจำลองบรรยากาศงานเทศกาลลอยกระทงในรูปแบบ 3 มิติ (3D Web Experience) ที่ผู้ใช้งานสามารถเข้าถึงได้ผ่าน Web Browser บนทุกอุปกรณ์ (PC, Tablet, Smartphone) พร้อมระบบประกวดและโหวตกระทงออนไลน์แบบเรียลไทม์

---

## 🌟 ฟังก์ชันเด่น (Key Features)

1. **ฉาก 3 มิติบรรยากาศงานลอยกระทง (Three.js):**
   - แม่น้ำจำลองคลื่นผิวน้ำสะท้อนแสงจันทร์ยามค่ำคืน
   - ดวงจันทร์เต็มดวงสว่างนวล
   - สถาปัตยกรรมไทย: วัดทรงไทย, เจดีย์ทองคำ, และบ้านเรือนไทยริมน้ำ
   - สะพานและท่าน้ำไม้พร้อมโคมไฟประดับ
   - ผู้คนเดินเที่ยวชมงานเทศกาลริมตลิ่ง

2. **ระบบกล้องควบคุมอิสระ (Camera Orbit Controls):**
   - หมุนฉากชมบรรยากาศได้ 360 องศา
   - ซูมเข้าและซูมออกได้อย่างอิสระ พร้อมระบบควบคุมขอบเขตกล้องเพื่อความลื่นไหล

3. **ระบบสร้างกระทง & ถ่ายภาพประกวดออนไลน์:**
   - ถ่ายภาพเซลฟี่แบบสดผ่านเว็บแคม หรือแนบรูปภาพจากมือถือ
   - **ฟังก์ชันย่อขนาดภาพอัตโนมัติ (Image Compression):** ย่อรูปให้มีขนาดไม่เกิน 500 KB ก่อนบันทึก
   - กรอกชื่อผู้ประกวด และคำอธิษฐานขอพรพระแม่คงคา
   - เลือกรูปแบบกระทง 3D ที่ชอบ (กลีบบัว, มรกตใบตอง, สุวรรณมาศ, ฯลฯ)
   - ปล่อยกระทงลอยลงสู่แม่น้ำ 3D พร้อมเสาแสงสีทอง (Beacon) นำสายตา

4. **ระบบแตะกระทง & โหวตให้คะแนน (Interactive Voting):**
   - แตะที่กระทงในแม่น้ำเพื่อเปิดหน้าต่าง Popup แสดงภาพผู้ประกวด คำอธิษฐาน และคะแนนโหวต
   - กดโหวตเพื่อสะสมคะแนนแบบเรียลไทม์

5. **ระบบคลาวด์และฐานข้อมูล (Cloud Firestore):**
   - เชื่อมต่อ Google Cloud Firestore จัดเก็บข้อมูลกระทง รูปภาพ และคะแนนโหวตแบบเรียลไทม์

6. **ระบบเสียงบรรยากาศไทย (Web Audio API):**
   - เสียงดนตรีไทยสังเคราะห์ (ขลุ่ย/ระนาด) ในตัว ไม่ต้องพึ่งพาไฟล์ภายนอก

---

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend:** React 19, Vite, Tailwind CSS v4
- **3D Graphics:** Three.js (WebGL, OrbitControls, Raycaster)
- **Database & Cloud:** Google Cloud Firestore (Firebase v12)
- **Icons & UI:** Lucide React, Canvas Confetti

## 🚀 วิธีติดตั้งและรันโปรเจกต์ (Getting Started)

1. **Clone repository:**
   ```bash
   git clone https://github.com/chonlasitk003/Loy-Krathong-Festival.git
   cd Loy-Krathong-Festival
   ```

2. **ติดตั้ง Dependencies:**
   ```bash
   npm install
   ```

3. **รันเซิร์ฟเวอร์สำหรับพัฒนา (Development Server):**
   ```bash
   npm run dev
   ```

4. **บิวด์สำหรับ Production:**
   ```bash
   npm run build
   ```
